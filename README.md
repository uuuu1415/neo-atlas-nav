# Neo Atlas Nav

个人网站导航项目。目标为 React 界面、玻璃拟态与丰富交互动效、网页管理、SQLite 数据、JSON 设置，以及 Linux 原生一键部署和内置更新。

**当前状态：基础导航、批量管理、JSON 设置、元数据预览、书签导入和完整备份恢复已实现，并通过服务测试及部分界面检查。拖拽、完整交互验收、部署与更新仍在开发中，尚未发布安装包。**

## 导入与备份

首页展开“导入与备份”，选择浏览器导出的 HTML 或本项目 JSON，先预览再确认导入。合并模式跳过重复 URL（包括回收站已有网站），嵌套书签文件夹转换为完整路径分类；不会抓取或自动收录其他网站。

JSON 导出包含分类、网站、标签、排序、回收站及设置。完整恢复会替换这些内容，需要勾选确认；恢复前的完整备份保存在服务器数据目录 `backups/before-restore-*.json`，页面显示对应文件名。导入文件最多 10 MB、10,000 个网站；当前完整备份格式也最多 10,000 个网站/分类，超大数据集支持仍待完善。

恢复日志配合 SQLite 提交标记处理应用中断，启动时恢复对应设置。当前按单应用进程运行设计；多实例并发与 Linux 断电耐久性尚未验收。设置继续独立存储于 `settings.json`。
